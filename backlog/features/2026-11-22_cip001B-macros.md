# Task: CIP-001B gpp macros

> **Note**: Backlog tasks are DOING the work defined in CIPs (HOW).

## Description

Define `\sessionstart`, `\sessionlength`, `\blocktime`, and `\timeplan` across notes / slides / null gpp sets. Macros must leave collectable markers (or equivalent) for the mdpp pass; they must not insert Reveal timer iframes unless the later timer-bridge task expands a `timer` flag.

## Acceptance Criteria

- [x] Macros defined in notes, slides-html, and null gpp sets
- [x] `\blocktime{minutes}{label}` and optional third arg `timer` parse without inserting classtimer chrome
- [x] `\timeplan` is a replaceable placeholder (not a full table yet)
- [x] Formats without a plan surface no-op or emit a short placeholder (same spirit as classtimer outside slides HTML)

## Implementation Notes

Follow the classtimer pattern in `lamd/macros/talk-macros-*.gpp`. Prefer markers the Python collect/emit pass can find after includes expand.
