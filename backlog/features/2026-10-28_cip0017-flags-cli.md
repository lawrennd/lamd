# Task: slidespdf flag and maketalk PDF CLI

> **Note**: Backlog tasks are DOING the work defined in CIPs (HOW).

## Description

Emit `--metadata slidespdf={out}.slides.pdf` from `flags post` when `slidespdf` is true. Change `maketalk --to pdf` (no `--format`) so it builds `${base}.notes.pdf` and `${base}.slides.pdf` instead of the missing `make pdf` target.

## Acceptance Criteria

- [ ] `flags post` includes `slidespdf=` when the field is true
- [ ] `maketalk --format slides --to pdf` still maps to `make ${base}.slides.pdf`
- [ ] `maketalk --to pdf` maps to both notes and slides PDF targets
- [ ] Existing `maketalk --format notes --to pdf` is unchanged

## Implementation Notes

Do not overload the existing `pdf:` Jekyll metadata field as the build switch.
