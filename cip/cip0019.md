## Summary

Add a first-class GPP macro `\answer{text}{blankheight}` that mirrors `notes.cls`:

```tex
\newcommand{\answer}[2]{#1}
\DeclareOption{student}{\renewcommand{\answer}[2]{\vspace*{#2cm}}}
```

Lecturer notes and all slides emit `text`. Student notes emit a blank of `blankheight` centimetres. The macro is an in-place slot, not an exercise wrapper.

Addresses [REQ-0013](../requirements/req0013_answer-slot.md). CIP-0017 listed student/lecturer `\answer` variants as out of scope; this CIP takes that work.

## Motivation

Reconstructed courses (NPA 2006 and others that used `notes.cls`) write derivations as `\answer{body}{vspace}` inside the notes body. Lecturer PDFs show the derivation; student PDFs leave a writing gap.

LaMD already has three nearby mechanisms, none of which is this slot:

| Mechanism | What it does | Why it is the wrong mapping |
|-----------|----------------|-----------------------------|
| `\notes{}` | Course-note body | The answer *is* notes body for the lecturer, and a gap for the student. `\notes{}` cannot switch on a student flag. |
| `\speakernotes{}` | Presenter aside (Reveal `<aside>`, empty elsewhere) | LyX yellow Note insets are speaker notes. `\answer` is assessed or worked material, not a sticky. |
| `\writeassignment{text}{marks}{answer}` | Numbered Exercise/Question; model answer only under `NOTES`+`IPYNB`+`ASSIGNMENTANSWERS` | Wraps the whole question, increments counters, and never prints the model answer in the notes PDF. |

A converter that emits `\notes{\subsection{Answer}}` plus body, or a local `\begin{answer}`, cannot reconstruct student blanks without a LaMD primitive.

## Detailed Description

### Public syntax

```markdown
\answer{the worked answer}{6}
```

Argument names in GPP are `text` and `blankheight`, not `body`/`vspace`. GPP substitutes `\vspace` as a parameter name and would collide with LaTeX `\vspace*`.

`blankheight` is a number of centimetres, matching `notes.cls` `#2` in `\vspace*{#2cm}`. Authors write `6`, not `6cm`.

The macro does **not** print a heading, increment an exercise counter, or award marks. Surrounding `\notes{}` / `\slides{}` / headings stay in the source.

### Context matrix

| GPP defines | Lecturer (default) | `-DSTUDENT=1` |
|-------------|--------------------|---------------|
| `NOTES` | emit `text` | emit blank of `blankheight` cm |
| `SLIDES` | emit `text` | emit `text` |
| neither (null, manim, …) | empty | empty |

Slides always show the answer. That matches the NPA `lectureSlides.lyx` preamble (`\newcommand{\answer}[2]{#1}`) and the archival slide PDF. Student blanks are a notes-class option, not a foil option.

### Flag plumbing

New preprocessor flag, independent of `assignment` / `ASSIGNMENTANSWERS` / `EXERCISES`:

1. `mdpp --student` appends `-DSTUDENT=1`.
2. `flags pp` emits `--student` when frontmatter `student: true` (same pattern as `assignment`).
3. `maketalk` already passes `PPFLAGS=$(shell flags pp $(BASE))`, so frontmatter is enough for a student notes PDF.

Use `getattr(args, "student", False)` in `mdpp` so existing tests that build an `argparse.Namespace` without the field do not break.

`assignment: true` continues to mean worksheet chrome and `\writeassignment` numbering. It does **not** imply student blanks. A lecturer worksheet can still show model answers.

### Macro placement

| File | Definition |
|------|------------|
| `talk-macros-null.gpp` | `\define{\answer{text}{blankheight}}{}` — gobble in unknown contexts |
| `talk-macros-notes.gpp` | lecturer: `text`; student: `\vspace*{\blankheight cm}` (pandoc `raw_tex` carries this into notes PDF) |
| `talk-macros-notes-html.gpp` | student override: `<div class="answer-blank" style="min-height:Ncm"></div>` so HTML/ipynb notes get a visible gap rather than a TeX command |
| `talk-macros-slides.gpp` | always `text` |

Do **not** put `\answer` in `talk-macros-exercises.gpp`. `\writeassignment` already has a third parameter named `answer`; that parameter is local to the define and must keep expanding to the model-answer argument under `ASSIGNMENTANSWERS`. A two-argument `\answer{text}{blankheight}` defined in notes/slides/null does not shadow that parameter.

### Alternatives considered

1. **Reuse `\writeassignment`** — rejected. It wraps the question as Exercise N and hides the model answer from the notes PDF unless `ASSIGNMENTANSWERS` is set, which is a notebook/lecturer-key path, not a student-blank path.
2. **`\ifdef{STUDENT}` in every source** — rejected. Authors would duplicate every derivation. The slot exists so the source stays one copy.
3. **Student blanks on slides as well** — rejected for v1. Archival slide decks showed the answers. A later CIP can add `student_slides` if a course needs blank foils.
4. **A LaTeX environment `\begin{answer}[n]…\end{answer}`** — possible as a notes-PDF-only implementation, but the authoring interface is the GPP macro so HTML, ipynb, and TeX share one source form.

### Out of scope

- FoilTeX chrome or a local `notes.cls` vendored into LaMD.
- Changing `\writeassignment` / `\exercise` / `\speakernotes`.
- NPA converter emission of `\answer{…}{…}` (lives in the course repo once this macro exists).
- `ASSIGNMENTANSWERS` as a CLI flag.

## Implementation Plan

1. **Macros** — define `\answer{text}{blankheight}` in null, notes, notes-html, and slides as in the table above.
2. **Flags** — `mdpp --student` → `-DSTUDENT=1`; `flags pp` → `--student` from frontmatter `student`.
3. **Tests** — GPP unit tests for lecturer notes, student notes (TeX vspace and HTML div), slides with and without `STUDENT`, and a writeassignment fixture that still prints its third argument under `ASSIGNMENTANSWERS`.
4. **Docs** — document the macro in `docs/contexts/teaching.md` and `docs/contexts/notes.md`; mention that slides always show the answer.

## Backward Compatibility

New macro and new optional flag. Sources that never call `\answer` are unchanged. `\writeassignment{text}{marks}{answer}` keeps its parameter name and `ASSIGNMENTANSWERS` behaviour. Frontmatter without `student` is lecturer mode, matching today's notes PDFs.

## Testing Strategy

- Unit: GPP expansion with `-DNOTES=1`, `-DNOTES=1 -DSTUDENT=1`, `-DNOTES=1 -DHTML=1 -DSTUDENT=1`, `-DSLIDES=1`, `-DSLIDES=1 -DSTUDENT=1`.
- Unit: `setup_gpp_arguments` includes `-DSTUDENT=1` only when `--student` is set.
- Unit: `flags pp` includes `--student` when mocked frontmatter `student` is true.
- Regression: `\writeassignment` under `NOTES`+`IPYNB`+`ASSIGNMENTANSWERS` still inserts the model-answer argument.
