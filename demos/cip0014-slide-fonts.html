CIP-0014

Slide font sizes

Deck talkfontsize: small (0.85×). Per-slide classes override.

Press →

Deck default (no class)

Body text at the deck scale (small / sm).

  • Useful for technical lectures
  • Equations and bullets stay denser
  • Headings use em and follow the base

Per-slide .font-xs

0.70× relative to the deck base — for dense derivations.

\[ \mathcal{L}(q) = \mathbb{E}_{q(\mathbf{z})}[\log p(\mathbf{x},\mathbf{z})] - \mathbb{E}_{q(\mathbf{z})}[\log q(\mathbf{z})] \]

Per-slide .font-sm

0.85× relative to the deck — same step as this deck’s frontmatter token.

Per-slide .font-md

1.00× relative to the deck — “normal for this talk,” not Reveal’s absolute default.

Per-slide .font-lg

1.15× — sparse emphasis.

Per-slide .font-xl

1.30× — key message.

Combined .font-sm .scrollable

Smaller type plus scroll for long reference lists.
